# Rooh Ali Web Studio - website

Plain HTML, CSS and JavaScript. No build step. Open `index.html` in a browser to preview.

## Files
- `index.html` Home
- `packages.html` Packages, package finder, process
- `skills.html` Skills
- `certificates.html` Certificates (open the original PDFs)
- `about.html` About and education
- `contact.html` WhatsApp and email only
- `style.css` All styling. Colours and fonts are at the top (`:root`).
- `main.js` Interactions
- `assets/` Logo, photo, studio artwork and certificate PDFs
